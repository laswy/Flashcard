    📖 Hướng Dẫn Sử Dụng

    🚀 Cách học cơ bản

    • Nhấn vào thẻ để xem nghĩa (lật thẻ)
    • 😓 Khó — đánh dấu từ chưa thuộc, ôn lại sau
    • ✓ Biết rồi — đánh dấu đã thuộc, tính vào tiến độ
    • Bấm 🔊 để nghe phát âm
    • Bấm ⭐ để thêm vào danh sách yêu thích

    ⚙️ Các chức năng

    • EN → VI: Học từ tiếng Anh sang tiếng Việt
    • VI → EN: Học từ tiếng Việt sang tiếng Anh
    • 🔀 Xáo bài: Trộn ngẫu nhiên thứ tự thẻ
    • 📝 Quiz: Chế độ trắc nghiệm 4 đáp án
    • 📤 Xuất: Xuất dữ liệu ra file JSON
    • 📥 Nhập: Nhập thêm từ vựng từ file JSON

    ➕ Thêm từ mới vào data.json

    {
  "id": 200,
  "category": "ISO Terms",
  "english": "Your Term",
  "vietnamese": "Nghĩa tiếng Việt",
  "example": "Example sentence in English.",
  "example_vi": "Câu ví dụ tiếng Việt.",
  "level": "Basic",
  "tags": ["quality"]
}

    Lưu file và tải lại trang. Hoặc dùng nút 📥 để nhập file JSON.

    🌐 Deploy lên GitHub Pages

    1. Tạo repo trên GitHub
    2. Upload 4 file: index.html, style.css, app.js, data.json
    3. Vào Settings → Pages → chọn branch main
    4. Truy cập link username.github.io/repo-name
